# MetaExchange — Layer di scambio tracciato (Hermeticum B.C.E.)

MetaExchange è il **nodo BCE** dedicato allo **scambio tracciato**:
ogni trasferimento di dato, valore o diritto è registrato, verificabile e opponibile.
